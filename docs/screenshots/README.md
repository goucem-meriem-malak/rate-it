# Screenshots

Put your phone screenshots here. The main README expects these names:

| File | Screen |
|---|---|
| `01-login.png` | Sign in |
| `02-signup.png` | Create account (create a group / I have a code) |
| `03-feed.png` | Group feed |
| `04-search.png` | Search |
| `05-title.png` | Title details and friends' ratings |
| `06-profile.png` | Profile and lists |

PNG or JPG both work. If you use a different extension or name, change it in `README.md`.
